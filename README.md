Contact School

About the Project

Contact School is a digital system designed to make communication between schools and students' guardians faster and easier.

In my school community, students' guardian phone numbers were stored and accessed through a large physical book. When a teacher or staff member needed to contact a student's guardian, they had to manually search through the book. This process could take time and was inefficient.

I created Contact School to transform this manual process into something much faster. Staff members can simply search for a student's name, and the corresponding guardian's phone number appears within seconds.

Why I Built It

The project started from a real problem I observed in my own school. My goal was to make a small but meaningful improvement to the daily lives of teachers and school staff.

Although it was created for my school community, the system was designed so that it could be adapted and used by other schools as well.

 How It Works

1. Student information is stored digitally.
2. The user searches for a student's name.
3. The system finds the corresponding student.
4. The guardian's contact information is displayed.
5. The user can use the number to contact the student's guardian.

Privacy

For the hackathon version, I replaced the real student information with fictional data. This prevents any real students' personal information from being exposed while still allowing the functionality of the prototype to be demonstrated.

Current Development

One challenge I faced while building the prototype was that the original student information was stored in a format that required me to manually enter everything into JSON files.

Because of this, I am working on a new feature that will allow student information to be added or updated directly from spreadsheets or photos of the data. This would make maintaining the system much faster and reduce repetitive manual work.

Use of AI

I used AI only in some parts of the code as a learning tool while developing the prototype. It helped me understand how to implement certain functionalities and solve coding challenges. The project idea, design, development process, and overall implementation were my own.
